# 32 通道校准与串扰补偿应用演示

## 已完成的功能与证据边界

入口：[32 通道应用演示](http://127.0.0.1:8000/replay.html)。启动 `python server.py` 后访问；仅监听本机默认端口 8000。页面支持三种场景、32 通道选择、播放/暂停、样本滑动和全通道残差显示。

本应用把已有矩阵乘核心用于**多通道增益与串扰补偿的合成数据回放**。不是传感器采集、实时处理系统或自动辨识算法；系数根据已知误差模型手工设定，不是大模型学习结果。复用了已验收的 PYNQ-Z2 / Zynq-7020 固件，没有新增综合、重烧固件、模型调用、板卡外设或云资源。

图中曲线来自独立的纯 Python 整数参考计算。三种场景的完全相同输入分别在实际板卡上执行一次，并与参考逐点比较；原始驱动不返回完整输出数组，故不能把图称为“现场 FPGA 输出采集曲线”。页面读取本地归档，不连接板卡，板卡断开后仍能演示。

## 固定协议

- 每种场景 256 个样本、32 通道，切成 8 个 32×32 矩阵帧；DDR 输入 int32，参考累加 int64。
- 输入范围遵守已有核心的 [-1000,1000] 契约，结果在 int32 范围内；软件参考和 NumPy 独立运算逐点相等。
- 每对通道下标从 0 开始。生成模型：`x偶 = 真值偶 + 真值奇/4`，`x奇 = 2×真值奇`。真值取 8 的倍数，除法精确，无随机噪声。
- 正常补偿：`y偶 = x偶 - x奇/8`、`y奇 = x奇/2`。矩阵列对应输出通道，`YQ8 = X × WQ8`，之后除以 256。W 的非零值为 256、128、-32。
- 关闭补偿：W 为 256 倍单位矩阵，输出等于输入。
- 额外偏置：生成输入后对 CH00–CH07 增加 24 counts，保留正常系数。这是明确的模型失配测试，不自动校正、重试或隐藏残差。
- 应用质量阈值预设为最大绝对误差 ≤ 1 count。质量是否达标，与 FPGA 是否正确执行矩阵运算分别判断。

| 场景 | 补偿前 RMSE | 补偿后 RMSE | 补偿后最大误差 | 应用质量 | 实板计算 |
| --- | ---: | ---: | ---: | --- | --- |
| 正常补偿 | 107.724765 | 0 | 0 | 达标 | 逐点相等 |
| 关闭补偿 | 107.724765 | 107.724765 | 256 | 不达标 | 逐点相等 |
| 额外偏置 | 108.391074 | 8.551316 | 21 | 不达标 | 逐点相等 |

误差单位为 counts，不附会成电压/压力等物理量；统计覆盖全部 32×256 个数。失配的前 8 通道残差交替为 21、12，其余为 0。零误差是受控可逆整数模型的预期结果，不代表真实设备达到无限校准精度。

## 现场讲解顺序（约 2 分钟）

1. 先声明“合成回放，不是传感器直播”，选择 CH01，展示输入增益偏差。
2. 切到关闭补偿，展示 RMSE 107.72 counts，说明“矩阵算对，不代表应用有效”。
3. 切到正常补偿，展示真值与补偿曲线重合、误差为零；播放并暂停，查看 32 通道残差。
4. 切到额外偏置，展示前 8 通道残差以及不达标告警，说明系统不会掩盖模型适用边界。
5. 展示页面下方输入/固件摘要和实板比较数，再打开固件交付页追溯到搜索候选、RTL 和布线。

此演示新增的是具体应用映射与可复算验证，不证明普遍模型优势、真实传感器效果或竞赛获奖等级。真实输入采集、系数辨识及同批 CPU/FPGA 重复性能对照属于独立后续工作。
